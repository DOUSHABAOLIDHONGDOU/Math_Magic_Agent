# 2019 数学建模 整数规划示例

## 摘要

本文针对路径规划问题，建立带容量约束的车辆路径规划 (CVRP) 整数规划模型，使用分支定界法和遗传算法求解。

## 模型建立

目标函数: min ∑∑ c_{ij} x_{ij}
约束: ∑_j x_{ij} = 1, ∀ i ∈ V \ {0} (每个客户恰好被访问一次)
∑_i x_{ij} = ∑_i x_{ji}, ∀ j (流量平衡)
u_i - u_j + Q x_{ij} ≤ Q - q_j (MTZ 子环消除)

## 模型求解

使用 Python 的 PuLP 库构建 MILP，由 CBC 求解器求解。对规模较大的实例改用遗传算法启发式求解。

## 误差分析

最优解与启发式解的间隙 (gap) 控制在 3% 以内。
