# 优秀论文对照评分表

Codex 在方案设计、论文写作和图表插入前，应对照本评分表检查。

## 摘要

| 检查项 | 要求 | 状态 |
|---|---|---|
| 问题概括 | 每个问题都有一句清楚概括 | 未检查 |
| 方法概括 | 写明核心模型和求解方法 | 未检查 |
| 结果概括 | 给出关键数值、排序、分类或决策 | 未检查 |
| 结论概括 | 明确回答题目要求 | 未检查 |
| 分问题表达 | 使用“针对问题一/二/三”的结构写清方法和结果 | 未检查 |
| 关键数值 | 摘要中出现关键结果、指标或排序 | 未检查 |

## 问题分析

| 检查项 | 要求 | 状态 |
|---|---|---|
| 题意拆解 | 明确每问输入、输出和目标 | 未检查 |
| 隐含约束 | 识别题目中的默认条件和边界 | 未检查 |
| 问题关联 | 说明各问之间的数据和模型继承关系 | 未检查 |

## 模型假设

| 检查项 | 要求 | 状态 |
|---|---|---|
| 假设必要 | 每条假设都服务模型简化 | 未检查 |
| 假设合理 | 不与数据和常识冲突 | 未检查 |
| 假设影响 | 说明可能带来的误差方向 | 未检查 |

## 模型建立

| 检查项 | 要求 | 状态 |
|---|---|---|
| 符号定义 | 主要变量和参数有符号表 | 未检查 |
| 数学表达 | 有清晰公式和目标函数 | 未检查 |
| 约束条件 | 约束完整、单位一致 | 未检查 |
| 流程图 | 关键模型有流程图或结构图 | 未检查 |

## 求解与结果

| 检查项 | 要求 | 状态 |
|---|---|---|
| 可复现 | 说明输入、算法、参数和输出 | 未检查 |
| 对比实验 | 至少包含基准或备选方案对比 | 未检查 |
| 结果解释 | 图表后必须有解释，不堆图 | 未检查 |
| 稳定性 | 对关键参数做敏感性分析 | 未检查 |

## 检验与分析

| 检查项 | 要求 | 状态 |
|---|---|---|
| 误差分析 | 说明误差来源和影响 | 未检查 |
| 敏感性分析 | 核心参数扰动后结果变化清楚 | 未检查 |
| 鲁棒性分析 | 数据扰动或模型选择变化时结论稳定 | 未检查 |
| 优缺点分析 | 结尾有模型优缺点和推广 | 未检查 |

## 图表

| 检查项 | 要求 | 状态 |
|---|---|---|
| 图题表题 | 中文题名清楚、编号连续 | 未检查 |
| 图表必要 | 每张图都服务一个结论 | 未检查 |
| 风格统一 | 字体、字号、颜色、线宽统一 | 未检查 |
| LaTeX 插入 | 路径、引用和位置正确 | 未检查 |
| 数据真实性 | 真实数据图必须来自可复现脚本，不得由生图替代 | 未检查 |

## 附录代码

| 检查项 | 要求 | 状态 |
|---|---|---|
| 核心代码 | 附录只放关键代码片段 | 未检查 |
| 运行说明 | 说明环境、依赖和执行入口 | 未检查 |
| 可读性 | 删除无意义注释和模板化痕迹 | 未检查 |
| 完整材料 | 完整代码在支撑材料中保留 | 未检查 |
| AI 痕迹整理 | 删除机械化模板痕迹，同时保留必要 AI 使用记录 | 未检查 |
