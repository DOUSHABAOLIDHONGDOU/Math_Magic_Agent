# First Trial Runbook

本手册用于跑通第一次完整训练。

## 0. 准备资料

- LaTeX 模板：已放入项目根目录压缩包。
- 历年优秀论文：已放入项目根目录压缩包。
- 训练题目：待导入。
- 数据附件：待导入。

## 1. Codex 初始化

1. 解压并整理模板和优秀论文。
2. 读取优秀论文 PDF。
3. 生成 `excellent_papers_notes.md`。
4. 根据优秀论文更新 `scoring_rubric.md`。

## 2. 导入题目

1. 将题面写入 `01_problem/problem_statement.md`。
2. 将数据说明写入 `01_problem/data_dictionary.md`。
3. Codex 识别每问的输入、输出、指标和边界。

## 3. 生成方案

对每个问题分别生成：

- Scheme A：稳健解释型。
- Scheme B：竞赛均衡型。
- Scheme C：冲奖增强型。

用户审批后进入实现。

## 4. 生成 Claude 工单

Codex 为每个问题每个方案生成工单。

示例：

- `04_claude_workorders/Q1_scheme_A_workorder.md`
- `04_claude_workorders/Q1_scheme_B_workorder.md`
- `04_claude_workorders/Q1_scheme_C_workorder.md`

## 5. Claude Code 实现

Claude Code 按工单输出：

- 代码
- 表格
- 基础图
- 运行日志
- 完成报告

## 6. Codex 验收

Codex 检查：

- 代码是否可运行。
- 模型是否未偏离路线。
- 结果是否合理。
- 图表是否支持结论。
- 是否需要补敏感性分析、误差分析和对比实验。

## 7. 用户确认模型

Codex 汇总三套方案结果，用户确认最终模型。

如果用户不满意：

- 重新生成方案。
- 或联网检索方法。
- 或要求 Claude Code 补跑。

## 8. 论文图表

Codex 负责最终图表：

- 真实数据图：基于结果和绘图脚本生成。
- 流程图/机制图：可使用生图技能或其他可视化工具。
- 图表审批后补入 LaTeX 并重新编译。

模型确认后先进入单题正文写作和 PDF 编译；用户审批图表后，再补入最终中文图。

## 9. 论文写作

Codex 写入：

- 问题重述
- 问题分析
- 模型假设
- 符号说明
- 模型建立与求解
- 结果分析
- 敏感性分析
- 误差分析
- 单题小结

以下总结性内容等全部小问完成后统一写：

- 摘要
- 优缺点
- 参考文献
- 附录代码
- AI 使用说明

## 10. 完成标准

第一次跑通至少完成：

1. 一个完整题目的三套方案。
2. 三套方案的代码结果。
3. 最终模型确认。
4. 一个小问 LaTeX 章节和编译后的 PDF。
5. 一版论文图表。
6. 一版代码附录。
