## 建模思路

将“达到 4% 浓度的最早时间”视为时间到事件问题，使用生存分析或区间删失思想。每名孕妇多次检测形成“未达标-达标”的观测区间，建模 BMI 对达标时间分布的影响，再按风险最小确定分组和时点。

## 数学模型

达标时间 $T_i^*$ 满足：

$$P(T_i^*\le t\mid BMI_i)=F(t\mid BMI_i).$$

最佳时点满足：

$$t_g=\arg\min_t \left[\lambda_1(1-F_g(t))+\lambda_2 r(t)\right].$$

## 算法流程

1. 由重复检测记录构造每名孕妇的达标区间。
2. 对未观察到达标的样本作为右删失。
3. 拟合 AFT/Cox 风格模型或离散时间 hazard 模型。
4. 由 BMI 分层预测达标分布。
5. 优化分组和时点，并做检测误差模拟。

## 预期输出

- 表格：每组达标时间分布参数、最佳时点、置信区间。
- 图：达标生存曲线、风险曲线、误差扰动图。

## 敏感性分析设计

| 参数 | 扰动范围 | 观察指标 |
|---|---|---|
| 删失处理 | 区间删失/右删失近似 | 最佳时点 |
| 风险权重 | 早检准确性 vs 晚检风险 | 时点变化 |
| 检测误差 | Y 浓度扰动 | 达标区间变化 |

## 优点

- 与“最早达标时间”高度贴合。
- 对多次检测数据利用更充分。

## 风险

- 生存分析解释复杂。
- Python 标准环境可能缺少专用生存分析库，需要用离散 hazard 模型近似。

## Claude Code 实现提示

- 优先实现离散时间逻辑 hazard，避免额外依赖。
- 输出每组 $F_g(t)$ 和风险最小点。
