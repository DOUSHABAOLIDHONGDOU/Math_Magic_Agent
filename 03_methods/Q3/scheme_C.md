# Q3 Scheme C

## 基本信息

- 问题：Q3
- 方案：C
- 定位：冲奖增强型
- 状态：待用户审批

## 建模思路

建立“检测误差-达标比例-潜在风险”的分布鲁棒优化模型。先用 bootstrap 或蒙特卡洛模拟生成 Y 染色体浓度扰动场景，再要求每组在多数场景下满足达标比例约束，选择最稳健的 BMI 分组和时点。

## 数学模型

设场景 $s$ 下组 $g$ 在时点 $t_g$ 的达标比例为 $p_{g,s}(t_g)$：

$$\min_{\mathcal{G},t_g}\frac{1}{S}\sum_s\sum_g R_{g,s}(t_g)+\eta\sum_g \max(0,p_0-p_{g,s}(t_g)).$$

其中 $p_0$ 为目标达标比例。

## 算法流程

1. 基于 Q3 多因素模型得到个体达标概率。
2. 对 Y 浓度和关键特征进行误差扰动。
3. 每个扰动场景下重新计算分组风险。
4. 选择在平均风险和最坏情形风险上表现稳定的方案。
5. 输出稳健性分析。

## 预期输出

- 表格：均值风险、最坏 10% 风险、分组时点。
- 图：误差场景下最佳时点分布、稳健风险箱线图。

## 敏感性分析设计

| 参数 | 扰动范围 | 观察指标 |
|---|---|---|
| 场景数 | 100、300、500 | 时点稳定性 |
| 误差标准差 | 0.3%、0.5%、1% | 风险 |
| 目标达标比例 | 90%、95%、97.5% | 时点 |

## 优点

- 对“检测误差”回应最充分。
- 结果更有冲奖表达空间。

## 风险

- 计算复杂度高。
- 风险函数和场景设定需要解释清楚。

## Claude Code 实现提示

- 使用固定随机种子。
- 输出场景级结果 CSV，供 Codex 生成稳健性图。
- 必须与 Scheme A/B 对比。
