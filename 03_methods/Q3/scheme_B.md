## 建模思路

使用可解释机器学习模型预测个体在不同孕周下的达标概率，并在 BMI 维度上做约束分组。模型选择随机森林、梯度提升或 HistGradientBoosting，并使用校准曲线保证概率可解释。

## 数学模型

训练模型：

$$\hat p_i(t)=f(t,BMI_i,Age_i,Height_i,Weight_i,q_i).$$

分组目标：

$$\min_{\mathcal{G},t_g}\sum_g \left[\lambda_1(1-\bar p_g(t_g))+\lambda_2r(t_g)+\lambda_3 Var_g(\hat p_i(t_g))\right].$$

## 算法流程

1. 构造达标标签和多因素特征。
2. 使用 GroupKFold 按孕妇代码分组验证，避免数据泄漏。
3. 训练可解释 ML 模型并做概率校准。
4. 计算不同 BMI 组和孕周下的平均达标概率。
5. 优化 BMI 分组与 NIPT 时点。

## 预期输出

- 表格：模型 AUC、Brier 分数、分组时点。
- 图：特征重要性、校准曲线、BMI 分组热力图。

## 敏感性分析设计

| 参数 | 扰动范围 | 观察指标 |
|---|---|---|
| 模型类型 | 逻辑回归/随机森林/梯度提升 | AUC、Brier |
| 校准方法 | 无校准/Platt/Isotonic | 风险曲线 |
| BMI 组数 | 3-6 | 总风险 |

## 优点

- 预测能力更强，适合多因素综合。
- 特征重要性可作为论文亮点。

## 风险

- 机器学习解释性弱于统计模型。
- 类别不平衡和重复检测必须处理。

## Claude Code 实现提示

- 使用 `GroupKFold`，分组字段为孕妇代码。
- 输出特征重要性和校准曲线数据。
- 不允许只报告准确率，必须报告 AUC/Brier/达标比例。
