## 建模思路

构建可解释机器学习分类器，将 X 染色体 Z 值、13/18/21 染色体 Z 值、GC 含量、读段数比例、BMI、年龄等作为特征，使用随机森林或梯度提升模型进行异常判定，并用特征重要性和 SHAP 近似解释模型。

## 数学模型

训练分类函数：

$$\hat y_i=f(Z_{13},Z_{18},Z_{21},Z_X,GC,Reads,BMI,Age,\ldots).$$

输出异常概率 $\hat p_i=P(y_i=1)$，根据验证集选择阈值。

## 算法流程

1. 清洗女胎数据，构造异常标签。
2. 删除空列和泄漏字段。
3. 构建数值特征和类别特征。
4. 使用分层交叉验证训练随机森林/梯度提升。
5. 调整分类阈值，优先保证异常召回率。
6. 输出特征重要性和分类结果。

## 预期输出

- 表格：模型指标、阈值、特征重要性。
- 图：PR 曲线、ROC 曲线、特征重要性条形图。

## 敏感性分析设计

| 参数 | 扰动范围 | 观察指标 |
|---|---|---|
| 分类阈值 | 0.2-0.8 | 召回率、精确率 |
| 模型类型 | 随机森林/梯度提升/逻辑回归 | AUC、F1 |
| 特征集合 | 全特征/仅染色体特征/加入 BMI | 指标变化 |

## 优点

- 分类能力强，能综合多指标。
- 图表表达丰富，适合竞赛论文。

## 风险

- 类别不平衡导致过拟合。
- 特征重要性不等于因果解释。

## Claude Code 实现提示

- 使用 `StratifiedKFold`。
- 指标必须包含 recall、precision、F1、ROC-AUC、PR-AUC。
- 输出阈值-指标曲线数据，供 Codex 选论文图。
