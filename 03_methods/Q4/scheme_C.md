## 建模思路

采用“异常检测 + 监督分类”的集成框架。先用无监督异常检测识别与正常女胎测序模式差异显著的样本，再与监督分类概率融合，得到更稳健的异常判定方法。适合异常样本少、标签可能不完备的情况。

## 数学模型

无监督异常分数：

$$s_i=h(X_i).$$

监督异常概率：

$$p_i=f(X_i).$$

融合判定：

$$P_i=\omega p_i+(1-\omega)\tilde s_i,\quad \hat y_i=\mathbf{1}(P_i>\theta).$$

## 算法流程

1. 清洗女胎数据并构造异常标签。
2. 用正常样本训练 Isolation Forest 或 One-Class SVM。
3. 用全部标签训练监督分类器。
4. 融合异常分数和分类概率。
5. 使用交叉验证选择 $\omega$ 和阈值 $\theta$。
6. 输出异常判定清单和解释图。

## 预期输出

- 表格：融合权重、阈值、分类指标、异常样本清单。
- 图：异常分数分布、二维降维可视化、PR 曲线。

## 敏感性分析设计

| 参数 | 扰动范围 | 观察指标 |
|---|---|---|
| 融合权重 $\omega$ | 0-1 | F1、召回率 |
| 异常检测污染率 | 2%、5%、10% | 异常清单稳定性 |
| 阈值 $\theta$ | 0.1-0.9 | 召回率、误报率 |

## 优点

- 对标签稀少和潜在漏标更稳健。
- 有较强创新性和图表空间。

## 风险

- 方法复杂，必须控制论文解释难度。
- 如果异常样本标签很可靠，集成模型未必优于监督模型。

## Claude Code 实现提示

- 使用 `IsolationForest` + `LogisticRegression` 或 `RandomForestClassifier`。
- 不引入额外重型依赖。
- 输出每个样本的监督概率、异常分数、融合分数和最终判定。
