# 论文图表生成与插入规则

## 总原则

论文最终图表由 Codex 负责生成、审美调整和插入 LaTeX。

真实数据图必须来自真实数据和可复现脚本。生图能力可用于流程图、机制图、结构示意图、场景示意图和视觉化辅助图，不用于伪造数值结果。

## 图表类型

| 类型 | 生成方式 | 负责人 | 是否可用生图 |
|---|---|---|---|
| 折线图、柱状图、散点图、热力图 | Python / MATLAB / R | Codex 审美，Claude 提供数据 | 否 |
| 模型流程图 | Mermaid / TikZ / 生图辅助 | Codex | 是 |
| 机制示意图 | TikZ / 生图辅助 | Codex | 是 |
| 地理或空间图 | GIS / Python | Codex 审美，Claude 提供数据 | 视情况 |
| 论文封面或非必要装饰图 | 不推荐 | Codex | 视情况 |

## 审批节点

每个问题的最终图表必须由用户审批后才能进入论文。

```markdown
## Figure Approval

- 问题：
- 图号：
- 文件：
- 表达结论：
- 用户意见：
- 是否通过：
```

## LaTeX 插入要求

- 所有图放入 `07_paper/figures/`。
- 所有表放入 `07_paper/tables/` 或直接由 LaTeX 表格生成。
- 图题使用中文，避免过长。
- 坐标轴、图例、图内主要标注必须中文；BMI、NIPT、GC、RMSE、R² 等通用缩写可保留。
- Claude Code 生成的英文图只能作为验收图或重绘参考，不能直接作为最终论文图。
- 正文必须引用图表，不允许孤立堆图。
- 图片文件名使用英文、数字和下划线。
- 最终图内不得出现“条件：变量取样本中位或均值”这类底部批注；这类条件写入正文、图注或表格备注。
- 最终图中不得使用红色虚线表示临床参考线、阈值或分组边界；若必须保留参考线，使用中性灰细点线，且不抢主图视觉重心。

## 版面与组合图硬约束

- 最终论文图必须服务单一主要结论；不要把验证、敏感性、误差、流程等不同结论拼成一张诊断大图。
- `subfigure` 可以使用，但最多两张，并且两张子图必须服务同一个比较结论；三宫格、四宫格或更多子图不得进入最终论文。
- 普通数据图建议宽度 `0.58\textwidth` 到 `0.70\textwidth`；热力图、流程图等复杂图最高不超过 `0.76\textwidth`，超过需用户单独审批。
- 单张图高度原则上不超过正文页高的 40%；任何占到半页左右的图都必须优先缩小、拆分或改成表格。
- 不允许连续堆图形成整页图。每页必须保留可读正文，图前或图后要有解释文字；跨小节处使用 `\FloatBarrier` 防止图漂移到错误位置。
- 表格后紧接双子图时，优先使用 `[!ht]`、适当缩小子图宽度，并在图后加 `\FloatBarrier`，避免 LaTeX 把图推到页底或让解释文字越过图提前出现。
- 每次图表入文后必须运行 `agentctl.py layout-check` 或 `latex-check` 内置版面检查；明确页码目标必须写成 `--expect-label-page label=page`。
- 模型检验和敏感性分析优先采用“表格摘要 + 单结论图”的组合，不使用四宫格图表面板。

## 每题入文规则

- 每完成一个问题的模型确认和图表审批后，Codex 必须将该问题的模型、结果表和中文图写入对应 `07_paper/sections/model_qX.tex`。
- 每写入一个问题后必须立即编译 `07_paper/main.tex` 生成 PDF，检查版面和图表引用。
- 摘要、问题整体分析、模型检验、模型评价及推广等总结性内容必须等全部问题完成后再填写。
