# 代码附录排版规范

## 原则

代码附录应符合中国数模论文常见风格：简洁、可读、可复现。

“减少 AI 生成痕迹”应理解为减少机械化模板痕迹和无意义注释，而不是删除必要的 AI 使用记录。

## 附录建议结构

```latex
\section*{附录}

\subsection*{附录 A 运行环境}

\subsection*{附录 B 核心代码}

\subsection*{附录 C 数据处理说明}

\subsection*{附录 D 完整代码文件说明}
```

## 代码选择

附录只放：

- 数据清洗核心函数。
- 主要模型求解函数。
- 关键参数设置。
- 主要绘图函数。

完整代码放支撑材料，不在论文正文中堆全部脚本。

## 风格要求

- 删除“generated by AI”等痕迹性文字。
- 删除解释变量赋值的无意义注释。
- 保留必要的算法说明。
- 统一函数命名、变量命名和缩进。
- 避免出现聊天式说明。
- 避免过长单行。
- 代码片段前后要有简短说明。

## 推荐 LaTeX 代码块

```latex
\begin{lstlisting}[language=Python,caption={核心模型求解代码}]
# code here
\end{lstlisting}
```
