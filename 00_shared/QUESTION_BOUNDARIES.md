# Question Boundaries

本文件记录题目边界、待确认问题和不可擅自修改的约束。

## 全局边界

- 训练目标：赛前训练，跑通多 Agent 数学建模流程。
- 论文风格：中文 CUMCM / 中国数模国赛论文风格。
- 默认代码语言：Python，已由用户批准。
- 三套方案：当前问题生成 A/B/C 三套方案，由用户选择一个或多个方案进入 Claude Code；未选方案保留为备选。
- 推进顺序：逐问推进，前一问模型确认前，后一问不能进入方案审批或 Claude Code 执行。
- 图表：最终论文图由 Codex 生成、审美调整和插入 LaTeX。
- Claude Code：只负责代码实现、调试和结果输出，不允许改建模路线。
- 冲突处理：提交给人类队伍仲裁。
